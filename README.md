# ⚡ Vite-JJSX

A lightweight, blazing-fast **Vite.js** template for building modern SPAs using React-like functional components without the library bloat.

---

## ✨ Key Features

* **🚀 Vite Dev Server** – Experience the speed of next-gen tooling with instant **HMR** (Hot Module Replacement).
* **🧩 JJSX Components** – Write clean, reusable, React-inspired functional components.
* **💻 Client-Side Rendering (CSR)** – Optimized for high-performance Single Page Applications.
* **💧 Client-Side Hydration** – Efficiently attach event listeners and state to your UI.
* **🗺️ App Navigation** – Smooth, client-side routing for a seamless user journey.
* **🟦 TypeScript** – First-class support for type safety and superior intellisense.
* **📦 Minimal & Modern** – No unnecessary boilerplate, just the essentials to get you coding.

---

## 🚀 Quick Start

1.  **Clone the repository:**
    ```bash
    npx degit ufukbakan/vite-jjsx-ssr your-project
    ```
2.  **Install dependencies:**
    ```bash
    cd your-project
    bun install
    # OR
    npm/pnpm/yarn install
    ```
3.  **Run development server:**
    ```bash
    bun run dev
    # OR
    npm run dev
    ```
